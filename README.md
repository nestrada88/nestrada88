# Software Engineering | Geospatial Systems

Software developer working across backend services, web applications, and native tooling, with a particular interest in geospatial computation, GPS navigation, and structured data processing.

My work emphasizes deterministic processing, explicit validation, maintainable architectures, and reproducible workflows.

### Technical Focus

- **Backend:** Python, FastAPI, REST APIs
- **Frontend:** React, TypeScript, Vite
- **Mobile:** Kotlin, Android
- **Geospatial:** GPX, GPS, WGS84, geodesic calculations, elevation analysis, reverse geocoding
- **Infrastructure:** Docker, Docker Compose, Nginx
